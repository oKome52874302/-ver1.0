# シフポケ

シフトを入れるだけでバイト代を自動で計算し、「今月いくら使えて、いくら貯まるか」がひと目でわかる学生向けのWebアプリです。

## できること

- **給料の自動計算**：時給／1回いくら、休憩、深夜割増（22〜5時）、土日加算、交通費、締め日・給料日、土日祝の振込ずれ（前営業日・翌営業日）
- **使えるお金**：前の月に振り込まれた給料で今月の出費をまかなう前提で、固定費・貯金・行事を引いた「自由に使えるお金」を表示
- **行事・出費の予算**：旅行などは「まとめる名前」で1枚のカードに集約。毎月の引き落とし（クレジットカードなど）も管理
- **貯金目標**：残高・目標額・期限から毎月の貯金額と、月末残高の予想を計算
- **実績**：月5万円、年間100万円などのメダルとランク
- **初回設定**：バイト先 → 貯金目標 → 固定費 の3ステップ

## 構成

- ビルド不要の静的サイトです（`index.html` 1ファイルにHTML・CSS・JavaScript）
- データは利用者のブラウザ（localStorage）にだけ保存します。サーバーやログインはありません
- `manifest.webmanifest` と `icons/` で、スマホのホーム画面に追加できます

```
index.html             アプリ本体
manifest.webmanifest   ホーム画面に追加するときの設定
icons/                 アプリアイコン（SVG と PNG）
```

## 手元で動かす

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` をそのまま開いても動きますが、ホーム画面追加などの確認はサーバー経由で行ってください。

## Cloudflare Pages で公開する

1. [Cloudflare](https://dash.cloudflare.com/) にログインし、**Workers & Pages → 作成 → Pages → Git に接続** を選ぶ
2. GitHub を連携して、このリポジトリを選ぶ
3. ビルド設定
   - フレームワーク プリセット：**なし**
   - ビルド コマンド：**空欄**
   - ビルド出力ディレクトリ：**`/`**
4. 「保存してデプロイ」。数十秒で `https://<プロジェクト名>.pages.dev` に公開されます

以後は `main` に push すると自動で本番に反映され、プルリクエストごとにプレビュー用の URL が発行されます。

## 注意

- ブラウザのサイトデータを消すと、入力内容も消えます（バックアップ・機種変更の引き継ぎは今後対応）
- 祝日はアプリ内で計算しています（振替休日・国民の休日・銀行休業日 12/31〜1/3 を含む）
- 年収の壁の目安額は制度改正で変わることがあるため、最新の情報を確認してください
